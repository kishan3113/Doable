# Doable UI Screenshot Index

Captured 13 October 2026 at localhost:3000 using the temporary local demo accounts. All screenshots are full-page JPEGs at the browser’s existing viewport; original dimensions are recorded in manifest.json.

Open index.html for a visual gallery, overview.jpg for a contact sheet, or an individual numbered file for full resolution.

## Coverage

- All 5 routed pages: login, worker registration, customer registration, worker dashboard, customer dashboard.
- Both login roles and temporary demo shortcuts.
- All 6 customer tabs: Profile, Search Worker, Book Worker, Track Request, My Bookings, Booking Info.
- All 4 worker tabs: Profile, My Bookings, Availability, Booking Details.
- Both profile editing forms, including the customer password-change form and worker photo selector.
- Initial and populated search/tracking/booking views, plus selected availability date.

Legacy components not imported by App.js have no accessible pages, so they are excluded. The wildcard route redirects to the already-captured login screen. Browser/OS file pickers, permission dialogs, every calendar month, and validation/status variants are not separate application pages. No forms that modify account or booking data were submitted.
